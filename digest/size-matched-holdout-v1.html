Conclusion

Matching tower size was not necessary for the better gold-label result in this comparison. The existing size-imbalanced pair scores 0.759 versus 0.697 for the closer-sized pair (-0.062 AUROC; paired 95% interval -0.106 to -0.019). The paired interval excludes zero in favour of the existing run. Yet the swapped pair improves validation retrieval by +1.33 percentage points. Better image–report matching did not yield better pathology readout here.

The larger text encoder overfitting the smaller image encoder is not demonstrated. Both runs show falling training loss and validation loss rising after its minimum; the closer-sized pair did not remove that pattern. This two-model swap cannot assign the cause to text capacity: the image backbone and readout width changed too. A four-cell image-size × text-size test would isolate those effects. This single-seed gold comparison does not establish a universal size rule.

What was held fixed

Gold-excluded cohort (3,478 training and 433 validation pairs), full original reports, 512 text tokens, E5 mean pooling with query: prefix, 130 mm MRI crop, batch size 32, 20 epochs, seed 2026, six LoRA blocks per tower, rank 64, alpha 128, optimizer rates, and retrieval-based checkpoint selection. The 56 gold cases were excluded from encoder training and selection; two locked gold test cases were not used.

This is a single-seed development comparison on a repeatedly examined gold cohort. The bootstrap resamples studies, not patients; shared patient identity cannot be verified. The new model has not been tested on the competition leaderboard.
